This one has taken many different iterations. It started out as CRUD application built for a Launch School project using Ruby and Sinatra. The focus was backend so the frontend was very basic HTML and CSS. Time passed and I wanted to learn Ruby on Rails, so I began building the site again from the ground up, which is what you see here (https://github.com/cameronbibb/backlog-up). However, I've had to put that development on pause. I still plan to get back to it. I've got some pretty exciting ideas and vision for it. As a big fan of videogames this project is particularly meaningful to me.
