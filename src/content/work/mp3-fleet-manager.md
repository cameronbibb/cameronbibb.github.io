The project is repoed in two different repoes. One for the kiosk app and one for the fleet manager dashboard. I'll add a more complete write-up for this project in the future.

For the time being, you can check out the kiosk app here: [MP3 Fleet Manager Kiosk App](https://github.com/cameronbibb/mp3kiosk) and the fleet manager dashboard here: [MP3 Fleet Manager Dashboard](https://github.com/cameronbibb/kiosk-console).
